# DynamixNetworks_Netflix_Analysis
# Netflix Movies & TV Shows Data Analysis

## 📌 Objective
Analyze Netflix dataset to identify trends in content type, genres, ratings, and release patterns.

## 🛠 Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn

## 📊 Key Insights
- Netflix has more Movies than TV Shows.
- Most content is rated TV-MA.
- USA produces the highest number of titles.
- Content increased significantly after 2015.
- Most movies are 80–120 minutes long.
- Drama and International genres dominate Netflix.

## 📁 Dataset
Netflix Movies and TV Shows dataset from Kaggle.

## 📈 Conclusion
Netflix shows rapid growth and focuses heavily on movies and mature content with diverse global genres.
